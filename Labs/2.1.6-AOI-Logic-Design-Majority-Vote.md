# 2.1.6 AOI Logic Design: Majority Vote

## Overview

Electronic voting systems must accurately convert individual votes into a final decision. In this project, you will design, simulate, and build a Majority Vote voting machine using only AND, OR, and inverter logic gates.

The voting machine has four inputs representing the votes of a president, vice-president, secretary, and treasurer. A candidate passes when a majority votes Yes. If the vote is tied, the president breaks the tie.

## Learning Objectives

By the end of this project, you should be able to:

- Translate a design scenario into a design brief.
- Create a truth table from design specifications.
- Write an unsimplified Sum-of-Products (SOP) expression.
- Implement an AOI logic circuit from an expression.
- Simplify an expression using Boolean algebra.
- Simulate and test an AOI circuit.
- Build and verify a simplified logic circuit using the Digital MiniSystem.

## Materials

- Computer with Circuit Design Software (CDS)
- Breadboarding hardware or Digital MiniSystem (DMS)
- Two-input AND gates (`74LS08`)
- Two-input OR gates (`74LS32`)
- Inverters (`74LS04`), as needed
- 22-gauge solid wire
- Multipurpose wire stripper
- Switches for circuit inputs
- Probe or LED circuit for output testing

# Design Challenge

A board of directors has four members:

- President
- Vice-president
- Secretary
- Treasurer

Each member casts one Yes/No vote.

A candidate is selected when a majority of the board votes Yes. If the vote is tied, the president’s vote breaks the tie:

- If the president votes Yes, the decision passes.
- If the president votes No, the decision fails.

Your task is to design, simulate, and build a digital Majority Vote voting machine using only AND, OR, and inverter logic.
