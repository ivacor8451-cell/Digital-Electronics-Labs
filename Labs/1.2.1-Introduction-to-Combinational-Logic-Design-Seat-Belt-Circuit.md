# 1.2.1 Introduction to Combinational Logic Design: Seat Belt Circuit

## Overview

Combinational and sequential logic are fundamental building blocks of digital electronics. In combinational logic, the output is a function of the current input values only.

In this activity, you will use AND, OR, and inverter gates to build and test a car safety buzzer circuit in Circuit Design Software (CDS).

## Learning Objectives

By the end of this activity, you should be able to:

- Differentiate among AND, OR, and inverter gates.
- Describe the behavior of a combinational logic circuit.
- Translate a written design statement into logic input and output conditions.
- Use CDS to build and test a combinational logic circuit.
- Compare expected outputs to simulated outputs.
