# 2.1.2 AOI Logic Analysis: Circuit to Truth Table to Logic Expression

## Overview

Engineers analyze logic circuits to determine what an existing circuit does and to verify that a new design works as intended. You can analyze an AOI logic circuit using two complementary methods:

- Determine the circuit truth table first, then derive the output logic expression.
- Determine the logic expression first, then derive the truth table.

In this activity, you will use both methods to analyze AOI logic circuits.

## Learning Objectives

By the end of this activity, you should be able to:

- Analyze an AOI logic circuit to determine its truth table.
- Derive an output logic expression from a truth table.
- Determine intermediate and final logic expressions directly from a circuit.
- Create a truth table from a logic expression.
- Compare two analysis methods to verify equivalent results.
