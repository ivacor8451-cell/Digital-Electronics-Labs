# 1.2.3 Binary Number System

## Overview

Humans commonly use the base-ten, or decimal, number system. Digital electronic systems, however, use two states: ON and OFF. For this reason, computers and digital devices use the base-two, or binary, number system.

In this activity, you will practice converting between decimal and binary numbers and identify patterns in binary place values.

## Learning Objectives

By the end of this activity, you should be able to:

- Convert numbers between decimal and binary number systems.
- Explain why digital devices use binary.
- Use correct base subscripts when writing numbers in different number systems.
- Differentiate between the most-significant bit (MSB) and least-significant bit (LSB).
- Identify patterns in binary counting.
