# 1.2.4 Introduction to Sequential Logic Design: Counters

## Overview

Sequential logic is a fundamental building block of digital electronics. Unlike combinational logic, sequential logic outputs depend on current inputs and previous output states. Clock signals control when changes occur, and flip-flops provide memory.

In this activity, you will use D-type flip-flops to investigate preset and clear functions, construct binary counters, measure counter signals, and build a 4-bit counter. 

## Learning Objectives

By the end of this activity, you should be able to:

- Describe how sequential logic differs from combinational logic.
- Investigate the operation of a D-type flip-flop.
- Construct and analyze 2-bit and 4-bit binary counters.
- Measure the period and frequency of counter signals.
- Explain how flip-flop stages divide a clock frequency.
- Build and verify a 4-bit counter using the Digital MiniSystem.
