# 1.1.9 Soldering: Random Number Generator

## Overview

In this project, you will assemble and test a Random Number Generator (RNG) kit. The completed device simulates a six-sided die by displaying a value from 1 to 6 with LEDs when the roll button is pressed.

Follow all soldering safety procedures. If you are not comfortable completing a step, stop and ask your teacher for help.

## Learning Objectives

By the end of this project, you should be able to:

- Apply safe soldering practices.
- Identify and correctly orient common electronic components.
- Assemble a through-hole printed circuit board (PCB).
- Test and troubleshoot an electronic circuit.
- Evaluate whether the RNG produces reasonably distributed results.

## Materials

- Random Number Generator kit
- Three AA batteries
- Double-stick tape
- Safety glasses
- Soldering iron
- Solder
- Damp sponge or brass wool tip cleaner
- PCB vise or board holder
- Flush cutters

## Resources

- Soldering the Random Number Generator presentation
- Soldering and Desoldering presentation
- SparkFun `How to Solder: Through-Hole Soldering` resource

## Safety

- Wear safety glasses whenever soldering or clipping component leads.
- Work in a well-ventilated area.
- Treat the soldering iron as hot at all times.
- Return the iron to its stand whenever it is not in use.
- Do not touch the iron tip, freshly soldered joints, or clipped leads.
- Lead clippings can fly when cut. Direct cutters away from yourself and others.
- Turn off and unplug equipment as directed by your teacher.

# Part B: Assemble the PCB

## 3. Install Resistors R1–R7

1. Locate an 180 Ω resistor.
2. Bend the leads as needed for insertion.
3. Insert the resistor into the PCB position marked `R1`.
4. Solder both leads on the back of the PCB.
5. Clip the excess leads flush with the board.
6. Repeat for the remaining 180 Ω resistors in positions `R2` through `R7`.

Keep each component flush to the PCB while soldering to provide mechanical stability.

## 10. Install IC Sockets

Install sockets before inserting the integrated circuits.

- `U1` uses an 8-pin socket.
- `U2` through `U6` use 14-pin sockets.
- Align the semicircular notch on each socket with the notch printed on the PCB.
- The notch identifies the pin-1 end of the socket.

### Install U1 Socket

1. Insert the 8-pin socket at `U1`.
2. Confirm the notch aligns with the PCB marking.
3. Solder pin 1 first.
4. Solder the opposite corner pin, pin 8.
5. Check that the socket lies flat on the PCB.
6. Solder the remaining pins.

### Install U2–U6 Sockets

# Part C: Functional Test and Troubleshooting

## 13. Install Batteries

Insert three AA batteries into the battery holder, following the polarity marks.

## 14. Functional Test

1. Slide switch `S2` to the ON position.
2. Verify that one or more LEDs turn on.
3. Press and hold pushbutton `S1`.
4. Verify that all LEDs flash.
5. Release `S1`.
6. Observe the flash rate decrease gradually until it stops.

If the RNG works as described, the assembly is complete.

| Test | Expected Result | Result |
|---|---|---|
| Switch `S2` turned on | One or more LEDs illuminate | Pass / Needs troubleshooting |
| Hold `S1` | LEDs flash | Pass / Needs troubleshooting |
| Release `S1` | Flash rate slows and stops | Pass / Needs troubleshooting |

## 15. Troubleshooting

If the functional test fails, troubleshoot in this order.

### Inspect Component Placement

Check the front of the PCB for:

- Incorrect LED orientation.
- Incorrect `C1` or `C2` capacitor orientation.
- Incorrect IC orientation.
- ICs that are not fully seated.
- Components placed in incorrect PCB locations.

### Inspect Solder Joints

Check the back of the PCB for:

- Cold solder joints.
- Solder bridges between adjacent pads or pins.
- Leads that were not soldered.
- Excess solder or damaged traces.

### Request Assistance

If component placement and solder joints appear correct, ask your teacher for help. A component may have been damaged before or during assembly.

# Part D: Random Result Test

## 16. Test RNG Fairness

A fair six-sided die should display each number about one-sixth of the time, or approximately 16.67% of the time.

Press the roll button 100 times. Record the displayed number after each roll. Tally the results and calculate the percentage for each value.
