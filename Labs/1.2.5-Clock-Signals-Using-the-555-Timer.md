# 1.2.5 Clock Signals Using the 555 Timer

## Overview

Digital electronic systems often use internal clocks, function generators, or software-generated signals. In some designs, however, engineers create a dedicated clock circuit. The 555 timer oscillator is a common introductory clock-signal circuit because it is inexpensive and relatively simple to design.

In this activity, you will simulate and build a 555 timer oscillator. You will investigate how resistor and capacitor values affect output frequency and duty cycle, then connect the oscillator to a 4-bit binary counter.

## Learning Objectives

By the end of this activity, you should be able to:

- Simulate a 555 timer oscillator.
- Calculate oscillator frequency and duty cycle.
- Measure oscillator signals using an oscilloscope.
- Determine how $R_A$, $R_B$, and $C_2$ affect frequency and duty cycle.
- Build a 555 timer oscillator.
- Use a 555 timer oscillator as a clock source for a 4-bit counter.

# Tinkercad Support

Check with your teacher to determine whether you will breadboard the 555 timer circuit.

If using Tinkercad, use:

- Small breadboard
- 555 timer
- Two capacitors
- Two 330 Ω resistors
- 5 V power supply
- LED and resistor for testing

Simulation timing may differ slightly from physical-circuit timing. The available resistor and capacitor values may also limit the frequency choices you can build.

If the timer is too fast, the 4-bit counter may not have enough time to propagate through the flip-flops, causing an incorrect count.

For the specified Tinkercad timer setup:

| Connection | Capacitor Value |
|---|---:|
| Control voltage | 10 mF |
| Trigger | 1 mF |
