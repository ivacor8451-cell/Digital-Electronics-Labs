# 2.1.3 AOI Logic Implementation

## Overview

A logic expression is a specification for a digital circuit. In this activity, you will implement AOI circuits from Boolean logic expressions in both Sum-of-Products (SOP) and Product-of-Sums (POS) form.

You will draw circuits using unlimited-input gates, redesign them using only available 2-input IC gates, simulate each circuit in Circuit Design Software (CDS), and build one implementation using the Digital MiniSystem.

## Learning Objectives

By the end of this activity, you should be able to:

- Implement AOI logic circuits from logic expressions.
- Differentiate between Sum-of-Products (SOP) and Product-of-Sums (POS) logic expressions.
- Design equivalent circuits using unlimited-input gates and 2-input gates.
- Simulate an AOI circuit using Circuit Design Software.
- Build and test an AOI circuit using the Digital MiniSystem.
- Compare equivalent AOI circuits that produce the same output.

## Materials

- Computer with Circuit Design Software (CDS)
- Breadboarding hardware or Digital MiniSystem (DMS)
- Hex inverter, such as a `74LS04`
- Two-input AND gate, such as a `74LS08`
- Two-input OR gate, such as a `74LS32`
- 22-gauge solid wire
- Multipurpose wire stripper
- LED and current-limiting resistor for testing
