# 2.1.4 Circuit Simplification: Boolean Algebra

## Overview

Boolean algebra is a mathematical system used to analyze and simplify digital logic. By applying Boolean theorems and laws, engineers can reduce a logic expression to a simpler equivalent expression. A simpler circuit generally uses fewer gates, is easier to build, and costs less to manufacture.

In this activity, you will use Boolean algebra to simplify logic expressions and a digital logic circuit.

## Learning Objectives

By the end of this activity, you should be able to:

- Apply Boolean theorems and laws to simplify logic expressions.
- Write simplified logic expressions in Sum-of-Products (SOP) form.
- Identify Boolean laws from equivalent logic expressions.
- Simplify a digital logic circuit by simplifying its output expression.
- Describe the benefits of simplifying digital logic circuits.

# Part A: Boolean Algebra Review

George Boole developed Boolean algebra in the 1800s. Although it originally had no practical application, Boolean algebra became an essential tool for designing and simplifying digital logic circuits.

Like traditional algebra, Boolean algebra uses rules to transform and simplify expressions. When an expression is simplified, the resulting circuit can perform the same function with fewer gates.
